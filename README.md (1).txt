# Ainur Rofik | Engineering Portfolio

Website portofolio responsif berbasis HTML, CSS, dan JavaScript. Bisa dipublikasikan gratis dengan GitHub Pages.

## File
- `index.html` : struktur dan isi website
- `style.css` : desain, layout, dan responsif untuk HP
- `script.js` : menu mobile, animasi saat scroll, dan form email

## Cara upload ke GitHub
1. Buat repository baru bernama `portfolio-engineering` dan pilih **Public**.
2. Upload ketiga file (`index.html`, `style.css`, `script.js`) ke root repository.
3. Buka **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu **Save**.
6. Tunggu proses selesai. URL biasanya `https://USERNAME.github.io/portfolio-engineering/`.

## Sebelum dipublikasikan
- Edit `CONTACT_EMAIL` di `script.js`.
- Edit email dan profil di bagian Contact pada `index.html`.
- Ganti contoh project dengan proyek nyata dan foto dokumentasi milikmu.
- Periksa kembali semua klaim skill dan pengalaman agar sesuai kemampuanmu.

Website memakai Google Fonts jika internet tersedia. Tanpa internet, font cadangan tetap akan digunakan.
